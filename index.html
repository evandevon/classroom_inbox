Classroom Inbox

For teachers

Students send work from PagePal and Word Helper straight to your Google Drive: one spreadsheet and one folder for each tool, all in a Classroom Inbox folder. Set it up once (step 1), then make a class QR code for each class (steps 2 and 3).

1 Set up the inbox

About 10 minutes, once. Already set up? Skip to step 2. Updating from an older version? Use the same Google Sheet and follow every step; your class QR codes keep working.

  1. Open a Google Sheet. New: go to sheets.new and name it “Classroom Inbox”. Updating: open the sheet you set up before.
  2. Paste the script. In the sheet, choose Extensions › Apps Script. Select everything in Code.gs, delete it, and paste this script in its place.

    This lets the script open only this sheet and the files it makes itself, never your other files.

  4. Add the Google Sheets API service. Next to Services (left-hand side), click +, choose Google Sheets API, then Add. (If it’s already listed, skip this.)
  5. Run setup. Click Save (the disk icon). In the function list at the top choose setup, then click Run. Allow access when Google asks.

    Google may say it “hasn’t verified this app”. It’s your own script, so click Advanced › Go to … (unsafe), then Allow.

    The Execution log then lists where each tool’s work goes and shows your secret code. Keep that code private; you need it in step 2.
  6. Deploy it.
    Deploy › New deployment. Click the cog next to Select type and choose Web app. Set Execute as: Me and Who has access: Anyone, then Deploy. Copy the Web app URL (it ends in /exec).
    Deploy › Manage deployments. Click the pencil (Edit), set Version to New version, then Deploy.

    The Version box is greyed out until you click the pencil. Don’t make a new deployment: updating the existing one keeps the same address, so your class QR codes and connected iPads keep working.

Want the Google Sheet inside the Classroom Inbox folder too? Drag it there in Google Drive yourself; the script can only move files it made.

3 Make a class QR code

Students scan it once with the iPad camera. From then on, work they send from PagePal or Word Helper arrives in your inbox.

Scan with the iPad camera

Keeping it safe
  • Show it while students connect, then take it down. Anyone who scans it before it expires can send work to your inbox (they can never read it).
  • If a QR code spreads, run cancelClassCodes in Apps Script: no new iPads can join with it, and joined iPads keep sending. To disconnect every iPad as well, run resetCode (they then need a new QR code).
  • Open students’ pictures and PDFs in Google Drive’s viewer rather than downloading them, and be wary of web links inside answers.

Turning the inbox off

Open your sheet, then Extensions › Apps Script. Choose a function from the menu at the top (next to Debug) and click Run. The Execution log confirms what happened.

Stop new iPads joining
Run cancelClassCodes. Every class QR code and link stops working, including ones that never expire. iPads that already joined keep sending.
Pause everything for now
Run pauseInbox. Students are told your inbox is turned off, and nothing is saved. Run resumeInbox to turn it back on; the address, secret code and QR codes stay the same.
Disconnect every iPad
Run resetCode. You get a new secret code, and students need a new class QR code to send again.
Turn it off for good
Deploy › Manage deployments, select the deployment, then click the Archive icon (the box with an arrow, next to the pencil). The web address stops working. To remove the script’s access to your Google account too, go to your Google account’s third-party connections and remove it. Your spreadsheets and PDFs stay in Drive until you delete them.

These switches need inbox script version 6 or later (step 2 shows your version). resetCode and archiving work with any version.
